<objective>
Build the deterministic gap analysis engine in `web/src/lib/core/gap/**`. `analyzeGaps(profile, schools, { today })` returns one `GapReport` per profile target. Each report covers GPA vs minimum and competitive GPA (null-safe, with a competitive fallback), units vs required (with semester/quarter conversion), per-prereq `met` / `missing` / `unknown-equivalency`, essays and recs needed, the next application deadline with days remaining, and feasibility warnings with stable codes. Every finding carries the `requirementId` and `sourceUrl` it came from. No LLM, no clock, no I/O.

Purpose: GAP-01 and GAP-02. Phase 4 (planner and tracker rows), Phase 5 (LLM phrasing, which must never change these findings), Phase 6 (eval oracle: the GPA-below-minimum, no-transfer-program, and quarter-unit scenarios) and Phase 7 (UI) all consume this output. Determinism is what makes those checks possible.
Output: 7 source files, 4 test files, and 1 snapshot, all under web/src/lib/core/gap/.
</objective>
