- `parseRetryAfterMs`:
  - `retry-after` numeric seconds → s*1000.
  - `retry-after` HTTP-date → `Date.parse - now`.
  - Else, when `x-ratelimit-remaining === '0'` and `x-ratelimit-reset` is present → `reset*1000 - now`.
  - Clamp to >= 1000. Return undefined when no signal is present.
- `createPacer`: serialize through a promise chain held in the closure (not module scope). Each call awaits the previous one, then sleeps `max(0, last + minInterval - now())`, records `last = now()`, and runs `fn`. Errors propagate to the caller, but the chain continues (`.catch(() => {})` on the chain link). Plan 10-02 imports this for Notion's 3 req/s limit.
