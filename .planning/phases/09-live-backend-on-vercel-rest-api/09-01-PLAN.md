<objective>
Build the REST surface of the live backend: `POST /api/plan`, `POST /api/execute` (NDJSON stream over a fetch POST) and `GET /api/evals`. Each request gets a fresh mock World. Approval is enforced on the server through the Phase 4 HMAC plan token, and real mode sits behind a shared-secret header. The logic lives in SvelteKit-only glue under `web/src/lib/server/`, and the handlers take env as a parameter so tests call them with plain `Request` objects.

Purpose: API-01. Vercel functions share no memory and Fluid compute runs concurrent requests in one instance (PITFALLS #5). So nothing may live in module state: the plan round-trips through the client with its token, and the world snapshot round-trips to demo idempotent re-runs.
Output: 3 server modules + 2 test files, 3 route files, `.env.example` additions.

## Wire contract (this plan defines it; 09-02 LiveSource and api-smoke consume it)

Errors (all JSON, `content-type: application/json`): `{ "error": <code>, "message": <string>, "details"?: string[] }`
| Code | Status |
|------|--------|
| invalid_json | 400 |
| invalid_body (zod failure on body shape) | 400 |
| invalid_profile | 400 |
| unknown_profile | 404 |
| invalid_plan (PolicyError) | 400 |
| invalid_world | 400 |
| invalid_plan_token (PolicyError) | 403 |
| real_mode_disabled / real_mode_forbidden | 403 |
| unknown_action_id (PolicyError) | 409 |
| payload_too_large (> MAX_BODY_BYTES = 1_000_000) | 413 |
| plan_signing_not_configured | 503 |
| internal_error | 500 |

`POST /api/plan` body: `{ profileId?: string; profile?: unknown; mode?: 'mock'|'real'; today?: 'YYYY-MM-DD' }`. Sending both profileId and profile is invalid_body. Sending neither uses 'demo'.
Response 200: `{ plan, planToken, preflight, reports, mode, llm: { kind: 'fake'|'hosted', model: string, reason?: string }, trace: TraceEvent[] }`

`POST /api/execute` body: `{ plan: unknown; planToken: string; approvedIds: string[] (max 500); profileId?: string; profile?: unknown; mode?: 'mock'|'real'; world?: unknown; today?: string }`
Response 200 headers: `content-type: application/x-ndjson; charset=utf-8`, `cache-control: no-cache, no-transform`, `x-accel-buffering: no`. One JSON object per line:
- `{"type":"start","runId":string,"planId":string,"mode":"mock"|"real","approved":number}`
- `{"type":"trace","event":TraceEvent}` (one per tracer event, in order)
- `{"type":"ping"}` every 10 s while running (keeps proxies from idling the connection)
- `{"type":"error","code":"run_failed","message":string}` (terminal; message truncated to 300 chars)
- `{"type":"done","report":RunReport,"world":WorldState|null,"trace":TraceEvent[]}` (terminal; `world` is null in real mode; `trace` is the full list, so a client that missed lines still gets everything, per PITFALLS #5)

`GET /api/evals` → 200 JSON of `static/data/evals.json` with `cache-control: public, max-age=60`, or 404 `{error:'evals_not_generated'}`.

**A. `web/src/lib/server/http.ts`** (no `$env`, no Node-only APIs, so it runs on any runtime):
- `export class ApiError extends Error { constructor(readonly status: number, readonly code: string, message: string, readonly details?: string[]) }` with name 'ApiError'. Export it from here and re-export it from runtime.ts.
- `export const MAX_BODY_BYTES = 1_000_000;` (Vercel caps bodies at 4.5 MB, PITFALLS #5; we stay well under.)
- `export function jsonError(status: number, code: string, message: string, details?: string[]): Response` → `new Response(JSON.stringify({ error: code, message, ...(details?.length ? { details: details.slice(0, 20) } : {}) }), { status, headers: { 'content-type': 'application/json; charset=utf-8', 'cache-control': 'no-store' } })`.
- `export function json(data: unknown, init?: ResponseInit): Response`, same headers plus status 200 by default. Use a local helper rather than `@sveltejs/kit` json so the module stays trivially testable.
- `export async function readJsonBody(request: Request, maxBytes = MAX_BODY_BYTES): Promise<unknown>`: check `content-length` first; then `text = await request.text()`; check `new TextEncoder().encode(text).byteLength > maxBytes` → 413; `text.trim() === ''` → `{}`; `JSON.parse` failure → ApiError(400,'invalid_json','Request body is not valid JSON').
- `export function safeEqual(a: string, b: string): boolean`: false if either is empty or the lengths differ. Otherwise XOR every char code into an accumulator over the full length and return `acc === 0`.
- `export function toErrorResponse(err: unknown): Response`: ApiError → jsonError(status, code, message, details). Anything else → `console.error('[api] internal error:', err instanceof Error ? `${err.name}: ${err.message}` : 'unknown')` and jsonError(500,'internal_error','Unexpected server error'). Never serialize env.

```ts
export const NDJSON_CONTENT_TYPE = 'application/x-ndjson; charset=utf-8';
export interface HandlerDeps {
  getEnv: () => Env;
  /** test seam: wraps createConnectors so tests can prove nothing is built on rejection */
  createConnectorsImpl?: typeof createConnectors;
  pingMs?: number; // default 10_000
}
type ApiEvent = { request: Request };
export function createPlanHandler(deps: HandlerDeps): (event: ApiEvent) => Promise<Response>;
export function createExecuteHandler(deps: HandlerDeps): (event: ApiEvent) => Promise<Response>;
export function createEvalsHandler(load: () => unknown): (event?: unknown) => Response;
```
The handlers accept `{ request }` only, which is assignable to SvelteKit's `RequestHandler`. Each handler body is wrapped in try/catch → `toErrorResponse(err)`.

**Plan handler:**
1. `env = deps.getEnv()`; `body = await readJsonBody(request)`, which must be a plain object (else invalid_body).
2. Validate the body with zod `PlanBody = z.object({ profileId: z.string().min(1).max(64).optional(), profile: z.unknown().optional(), mode: z.unknown().optional(), today: z.string().optional() })`; failure → invalid_body.
3. `mode = resolveRequestMode(env, request.headers, body.mode)`; `planSecret = requirePlanSecret(env)`; `profile = resolveProfile(body)`.
4. `mem = new MemorySink()`; `{ rt, llmInfo, createdAt } = createRequestRuntime({ env, mode, planSecret, sinks: [mem], today: body.today, createConnectorsImpl: deps.createConnectorsImpl })`.
5. `{ plan, planToken, reports } = await planSprint(rt, { profile, schools: getSchools(), createdAt })`.
6. `preflight = await preflightPlan(rt.connectors, plan)`. This is read-only; it drives the UI's New/Exists badges.
7. Return `json({ plan, planToken, preflight, reports, mode, llm: llmInfo, trace: mem.events })`.

**Execute handler.** Everything before the stream opens can still return a proper status code:
1. Read and zod-validate the body: `ExecuteBody = z.object({ plan: z.unknown(), planToken: z.string().min(1).max(512), approvedIds: z.array(z.string().min(1).max(128)).max(500), profileId, profile, mode, world: z.unknown().optional(), today })`.
2. `mode = resolveRequestMode(...)`; `planSecret = requirePlanSecret(env)`; `profile = resolveProfile(body)`; `worldSnap = parseWorldSnapshot(body.world)`. In real mode a world is rejected inside createRequestRuntime; do that check here too so it happens before connectors exist.
3. **Pre-check (no connectors yet):** `auth = await authorizeExecution({ plan: body.plan, planToken: body.planToken, approvedIds: body.approvedIds, secret: planSecret, recipientAllowlist: recipientAllowlistFromProfile(profile) })` in try/catch. On `PolicyError` map `code` to a status: invalid_plan → 400, invalid_plan_token → 403, unknown_action_id → 409. Throw `ApiError(status, code, err.message, err.details)`. This is what makes "tampered → 403, writes nothing" true. executeSprint re-authorizes inside (defense in depth), which is intended.
4. Build the stream. Set `const enc = new TextEncoder()`, `trace: TraceEvent[] = []`, `let closed = false`, and `send(obj)` which does `if (!closed) controller.enqueue(enc.encode(JSON.stringify(obj) + '\n'))` inside try/catch (a client disconnect sets `closed = true`).
   ```ts
   const stream = new ReadableStream<Uint8Array>({
     async start(controller) {
       const sink = new CallbackSink((e) => { trace.push(e); send({ type: 'trace', event: e }); });
       const { rt, world } = createRequestRuntime({ env, mode, planSecret, world: worldSnap, sinks: [sink], today: body.today, createConnectorsImpl: deps.createConnectorsImpl });
       const runId = `run-${rt.tracer.traceId}`;
       send({ type: 'start', runId, planId: auth.planId, mode, approved: auth.approved.length });
       const ping = setInterval(() => send({ type: 'ping' }), deps.pingMs ?? 10_000);
       try {
         const report = await executeSprint(rt, { plan: body.plan, planToken: body.planToken, approvedIds: body.approvedIds, profile, runId });
         send({ type: 'done', report, world: world ? world.snapshot() : null, trace });
       } catch (err) {
         console.error('[api/execute] run failed:', err instanceof Error ? `${err.name}: ${err.message}` : 'unknown');
         send({ type: 'error', code: 'run_failed', message: (err instanceof Error ? err.message : 'Run failed').slice(0, 300) });
       } finally { clearInterval(ping); closed = true; try { controller.close(); } catch {} }
     },
     cancel() { closed = true; }
   });
   return new Response(stream, { status: 200, headers: { 'content-type': NDJSON_CONTENT_TYPE, 'cache-control': 'no-cache, no-transform', 'x-accel-buffering': 'no' } });
   ```
