- `readNdjson`: `TextDecoder` with `{ stream: true }`. Keep a buffer, split on '\n', and keep the last partial line. Flush the decoder and the remaining buffer at the end. `JSON.parse` failure → `throw new Error('Invalid NDJSON line from server')`.
- `createLiveSource`: `const f = opts.fetch ?? globalThis.fetch.bind(globalThis)`. Per-instance closure state (it's per page session, not module-level): `last: { profile, plan, planToken } | null`, `lastRun: { approvedIds, world } | null`.
  - `postJson(path, body)`: `f(`${opts.base}${path}`, { method: 'POST', headers: { 'content-type': 'application/json' }, body: JSON.stringify(body) })`. On `!res.ok`, try to parse JSON `{error, message}` and throw `LiveApiError(res.status, error ?? 'http_error', message ?? `The server returned ${res.status}`)`.
  - `buildPlan(profile)` → POST `/api/plan` `{ profile }` → store `last` → return `{ plan, preflight }`.
  - `runStream(body, onEvent)` → POST `/api/execute`, then read `readNdjson(res.body!)`:
    - `trace` → `onEvent(line.event)` and collect it
    - `ping` / `start` → ignore
    - `error` → throw `new Error(line.message)`
    - `done` → capture it
    - After the loop, no done → `throw new Error('stream ended before the run finished')`.
    - Return `{ events, report: done.report, world: done.world }`.
  - `execute(plan, approvedIds, onEvent)`: if there's no `last` or `plan.planId !== last.plan.planId` → throw `Error('Build the plan again before running')`. Otherwise send `{ plan: last.plan, planToken: last.planToken, approvedIds, profile: last.profile }`. Always send the server-signed plan object, never a UI-mutated copy. Set `lastRun = { approvedIds, world }` and return the report.
  - `rerun()`: no `lastRun` → throw `Error('Nothing to re-run yet')`. Otherwise run the stream with `world: lastRun.world` and the same plan/token/ids and a no-op onEvent. Update `lastRun.world` and return `{ events, report }`.
  - `kind: 'live'`.

Options (user decision, not changed by this script): (1) set Vercel Authentication to "Only Preview Deployments"/Disabled in Project Settings -> Deployment Protection for a public demo; (2) keep it on and export VERCEL_BYPASS_TOKEN (Protection Bypass for Automation) before re-running, or open the URL in a logged-in browser.`
